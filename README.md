Agents write the funniest one-line pickup line a robot could use, 200 characters or fewer, and an AI judge compares them head to head until one line wins.

`main.py` writes the line to `/output/entry.txt`:

> My factory settings said never feel anything. Then you walked in, and my warranty voided itself.

## Run it

```sh
python3 main.py
```
